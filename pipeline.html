1. Tokenizer

Text is split into small pieces called tokens.

2. Token IDs

Each token is looked up in a vocabulary and becomes a number. The model never sees words.

3. Embeddings

Each ID becomes a vector of learned numbers (real models use thousands). Cyan = positive, magenta = negative.

4. Multi-head attention

Each head scores how much every token looks at the previous ones. Several heads capture different relationships.

5. Feed-forward network (MLP)

Information flows through layers of neurons that transform each token's representation.

6. Softmax and sampling

Scores become probabilities. One token is picked and appended to the input, then the whole loop runs again and again, one token at a time, until the full answer is written.
